# Risk: RIS-006 Nondeterministic Output Across OS/Filesystems

Outputs (lists, diagnostics, file enumerations) can vary across OS/filesystems due to enumeration order, case-sensitivity defaults, and path normalization differences, undermining determinism and testability.
