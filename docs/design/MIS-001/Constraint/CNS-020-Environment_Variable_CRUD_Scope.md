# Constraint: CNS-020 Environment Variable CRUD Scope

Alfred MUST NOT expose standalone environment-variable CRUD tools. If environment-variable behavior is supported, it MUST be scoped to Alfred-controlled contexts (e.g., managed .env files or tool-scoped environments) and MUST NOT claim to mutate the parent IDE or shell environment across OSes.
